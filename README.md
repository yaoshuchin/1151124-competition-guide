# 科技教育創意實作競賽【資訊科技組】 程式實作解題與競賽全攻略

> 🏆 專為教育部國民及學前教育署「科技教育創意實作競賽【資訊科技組】」選手培訓、指導教師與學生量身打造之實戰教學與線上即時評測驗證系統。

---

## 🌟 核心特色

1. **Scratch × Blockly 雙軌積木實戰對照**：
   - 深入剖析兩種競賽常見積木環境的運作差異（事件驅動 vs 直接執行）。
   - 標準輸入輸出（I/O）規範指引：「詢問/讀取」 vs 「說出答案（評分）」 vs 「訊息視窗（除錯）」，避免因輸出積木用錯造成 0 分。
2. **全收錄 11 大核心競賽題庫與演算法**：
   - **入門基礎**：數列加總（清單法 vs 累加變數法）、超商收銀結帳（迴圈累加、找零與防呆）。
   - **經典題庫**：偶數和（餘數定理與步進優化）、三角形判斷（最長邊優化算法）、刮刮樂六六大順（數值商餘拆解法 vs 字串轉型防扣分避坑）、遊樂場門票（貪婪配對省錢法）、歌唱比賽成績（去極端值求平均、清單 `- 0` 型別轉換防坑）、質數和（因數迴圈篩選、無解輸出 0 邊界處理）。
   - **競賽進階實戰**：防災演習（臨時屋容量累加、0 人優先邊界判斷）、電影院找座位（連續座位排列組合推導 `座位 - 人數 + 1`）、大富翁環形棋盤（餘數定理循環座標公式 `(pos - 1 + step) % N + 1`、非負保底與起點不結算規則）。
3. **52 張高畫質官方解法積木截圖**：
   - 內建全螢幕高清縮放燈箱（Lightbox），支援鍵盤左右箭頭導覽與 Esc 快速關閉，積木文字清晰無比。
4. **⚡ 線上即時評測與一鍵全自動批次測試系統**：
   - 「師大只能一個個手動驗證，而我們平台可以一鍵全部一起驗證！」
   - 支援 35+ 組官方測資一鍵全自動批次執行，即時回報 PASS / FAIL 與毫秒級耗時，100% 全數通過時施放慶祝彩帶！
   - 個別題目支援自訂輸入測試、一鍵帶入官方範例，快速除錯。
5. **個人化與無障礙體驗**：
   - 深色 / 淺色模式切換（Dark/Light Mode）。
   - 字級放大/縮小調整（A- / A+）。
   - 學習掌握進度追蹤（localStorage 自動保存學習狀態）。
   - 響應式 RWD 設計，手機、平板、電腦與投影機皆完美適配。
